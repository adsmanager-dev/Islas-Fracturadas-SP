# Validación 3DEN

## Flujo

1. Leer docs 10, 11, 18 y criterios de evidencia en 19.
2. Identificar objeto, coordenadas, capas, dependencias y criterio observable.
3. Preparar pasos manuales reproducibles sin editar `mission.sqm` como texto.
4. Verificar rutas, navegación IA, spawns, líneas de visión, colisiones y composición.
5. Probar estados relevantes, guardado/carga y rendimiento cuando aplique.
6. Registrar versión, escenario, capturas/RPT, resultado y defecto asociado.

## Salida

Entregar checklist ejecutable y registro de evidencia. Usar `VALIDADO_3DEN` solo después de una ejecución documentada; si Codex no puede operar el editor, marcar la validación como pendiente manual.
