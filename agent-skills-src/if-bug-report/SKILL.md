# Informe de defecto

## Flujo

1. Registrar versión, entorno, escenario, mods y estado inicial.
2. Reducir pasos hasta una reproducción mínima y determinista.
3. Separar esperado, resultado real e impacto observable.
4. Adjuntar RPT, captura, save, archivo o diff pertinente sin secretos.
5. Asignar severidad por impacto y frecuencia, no por frustración.
6. Identificar propietario probable, regresión, workaround y dependencias.
7. Formular criterio de cierre y prueba de regresión requerida.

## Salida

Entregar título, severidad, entorno, precondiciones, pasos, esperado, real, frecuencia, evidencia, impacto, sospecha técnica marcada como hipótesis y criterio de aceptación.
