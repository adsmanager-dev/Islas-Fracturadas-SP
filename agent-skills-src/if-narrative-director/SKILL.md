# Dirección narrativa

## Fuentes

Leer el índice y las fuentes 05–09 y 15–17; consultar 02–03 cuando intervengan historia, Helios, PHAROS o Argos.

## Flujo

1. Definir fantasía, pregunta dramática y cambio irreversible del arco.
2. Identificar actores autónomos, objetivos, recursos, relojes y conocimiento disponible.
3. Escalar al menos dos ejes entre actos y reservar recuperación tras los picos.
4. Diseñar decisiones con coste, señales previas, consecuencias inmediatas y diferidas.
5. Vincular acto → facción → personaje → misión → consecuencia → familia de final.
6. Proteger `DEC-003`–`DEC-005` y evitar metaconocimiento en contenido para jugador.

## Salida

Entregar premisa, secuencia causal, estados por actor, revelaciones autorizadas, decisiones, consecuencias, finales preparados, trazabilidad y pendientes. Etiquetar todo contenido nuevo como propuesta hasta aprobación.
